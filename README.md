# divanny-zal
Стек
Чистые HTML, CSS и JavaScript.
Что умеет
Показывает адаптивную раскладку: на 320 px один столбик, от 640 px две колонки, от 1024 px три.
Рисует карточки из массива-заглушки.
Обрабатывает пустой список и выводит подсказку.
Использует цветовую палитру через CSS-переменные в :root.
Поддерживает видимый фокус при навигации по Tab.
Связывает подписи полей с элементами через label и id.
Что сделано с помощью ИИ
Каркас index.html, style.css и script.js написаны моделью Qwen по моим промптам.
Я прочитал код, разобрал его построчно и проверил в браузере.
Сообщения коммитов сформулированы по правилам курса и проверены вручную.
